# Vibe Coding MVP 文档索引

本目录保存 Vibe Coding 课程平台 MVP 的产品与课程文档。

本目录包含已确认的产品、角色、课程、页面、决策和第一阶段技术设计。尚未确认的内容统一使用 `TODO` 标记。

## 文档说明

| 文件 | 作用 |
| --- | --- |
| `01-product-requirements.md` | 说明产品目标、目标用户、MVP 范围、核心流程和验收标准。 |
| `02-role-matrix.md` | 说明当前产品中各角色的目标、职责、能力和边界。 |
| `03-course-outline.md` | 汇总 5 个单元、13 次课的定位、目标、学习步骤和课程衔接。 |
| `04-page-map.md` | 说明当前页面、页面内容、主要操作和页面之间的跳转关系。 |
| `05-decisions.md` | 记录本轮已确认的产品与课程决策，避免后续重复讨论。 |
| `06-architecture.md` | 分析当前 MVP，并定义目标结构、五端路由、课程渲染和存储边界。 |
| `07-course-schema.md` | 定义课程、单元、课次、六步和互动原子的目标 JSON/Zod 结构。 |
| `08-data-model.md` | 定义五角色共享的组织、班级、进度、作品和反馈数据模型。 |
| `09-implementation-plan.md` | 按创造台底层、四组课程工具、五端联动和全站部署拆分后续阶段。 |
| `10-test-plan.md` | 定义五端、课程 JSON、进度、设备适配和质量命令测试。 |
| `creative-workbench-spec.md` | 定义“造物星球·创造台”的页面结构、ProjectDocument、同步、存储和工具注册机制。 |
| `lesson-interaction-matrix.md` | 记录 13 课连续项目输入、六步互动、工具、测试、产出和多端摘要。 |
| `references/` | 存放后续确认采用的参考材料；当前暂未收录材料。 |

## 使用约定

- 已确认的事实直接记录。
- 尚无结论的内容标记为 `TODO`。
- 产品范围变化时，优先更新产品需求和决策记录。
- 课程内容变化时，优先更新课程大纲。
- 页面增删或导航变化时，更新页面地图。

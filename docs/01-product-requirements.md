# Vibe Coding 创意编程课程平台产品需求文档

## 1. 文档目的

本文档用于明确 Vibe Coding 创意编程课程平台的产品定位、目标用户、课程目标、教学节奏、产品形态、第一阶段建设范围、非建设范围、技术基础与视觉要求。

本文档只记录已经确认的产品需求，不包含未经确认的功能。

## 2. 项目概述

### 2.1 项目名称

Vibe Coding 创意编程课程平台。

### 2.2 产品定位

Vibe Coding 创意编程课程平台是一个面向小学高年级至初中阶段学生的创意编程课程平台。

平台以自然语言与 AI 协作为主要学习方式，以 JSON 驱动原子化课程内容。课程内容与页面代码分离，由 LessonRenderer 根据课程内容调用不同互动组件，形成统一、可连续体验的课程学习过程。

### 2.3 产品目标

- 为学生提供完整、连续的创意编程课程体验。
- 让学生通过自然语言与 AI 协作完成网页应用学习与创作。
- 为总部、合作伙伴、教师和家长提供符合各自角色需要的演示入口与信息视图。
- 使用模拟身份和模拟数据完成第一阶段产品验证。
- 确保网站可以独立运行和部署。

## 3. 目标用户

平台面向以下五类用户：

| 用户角色 | 角色说明 |
| --- | --- |
| 总部 | 查看课程结构、校区和整体数据。 |
| 合作伙伴 | 查看所属校区的班级、教师和课程数据。 |
| 教师 | 查看课程、班级、学习进度和学生作品。 |
| 学生 | 体验 13 次课程，完成学习任务与网页应用作品。 |
| 家长 | 查看学生的学习进度和学习成果。 |

第一阶段使用模拟身份进入不同演示端口，不包含真实账号注册和登录。

## 4. 课程规划

### 4.1 课程规模

- 课程共 5 个单元。
- 课程共 13 次。

### 4.2 课程目标

学生通过自然语言与 AI 协作，逐步学习以下内容：

1. 网页结构。
2. 视觉样式。
3. 页面组件。
4. 点击事件。
5. 输入输出。
6. 条件判断。
7. 状态记录。
8. 测试调试。
9. 应用发布。

完成全部课程后，学生最终完成一个可独立运行的网页应用。

### 4.3 核心教学节奏

每次课程统一采用以下教学节奏：

1. 看案例。
2. 懂原理。
3. 拆任务。
4. 动手做。
5. 运行测试。
6. 讲出理解。

统一教学节奏用于保持不同课程之间的学习体验一致，并支持学生从观察、理解到实践、验证和表达的完整学习过程。

## 5. 产品形态

平台采用 JSON 驱动的原子化课程形态：

- 课程内容与页面代码分离。
- 课程内容由 JSON 组织。
- 页面通过 LessonRenderer 读取课程内容。
- LessonRenderer 根据课程内容调用不同互动组件。
- 学习进度使用 localStorage 保存在本地设备。

## 6. 第一阶段产品范围

### 6.1 多角色演示

- 总部、合作伙伴、教师、学生和家长五种身份可以进入不同演示端口。
- 第一阶段使用模拟身份和模拟数据。

### 6.2 学生端

- 学生可以体验完整的 5 个单元、13 次课程。
- 学生按照统一教学节奏完成每次课程。
- 学生通过自然语言与 AI 协作进行学习和创作。
- 学生最终完成一个可独立运行的网页应用。

### 6.3 教师端

- 教师可以查看课程。
- 教师可以查看班级。
- 教师可以查看学生学习进度。
- 教师可以查看学生作品。

### 6.4 家长端

- 家长可以查看学生学习进度。
- 家长可以查看学生学习成果。

### 6.5 总部端

- 总部可以查看课程结构。
- 总部可以查看校区。
- 总部可以查看整体数据。

### 6.6 合作伙伴端

- 合作伙伴可以查看所属校区的班级数据。
- 合作伙伴可以查看所属校区的教师数据。
- 合作伙伴可以查看所属校区的课程数据。

### 6.7 运行与部署

- 网站可以独立运行。
- 网站可以独立部署。

## 7. 第一阶段暂不包含

第一阶段明确不包含以下内容：

1. 真实账号注册和登录。
2. 正式数据库。
3. 财务与支付。
4. 真实招生系统。
5. 真实 AI 接口。
6. 正式语音接口。
7. 复杂的权限后台。

## 8. 技术基础

第一阶段使用以下技术基础：

- Next.js。
- TypeScript。
- Tailwind CSS。
- Zod。
- JSON。
- LessonRenderer。
- localStorage。

## 9. 视觉与设备要求

### 9.1 视觉风格

- 使用浅灰白背景。
- 使用紫色作为主要强调色。
- 信息表达清楚、简洁。
- 具有适度的科技感。
- 具有儿童友好感。

### 9.2 设备适配

- 适合电脑使用。
- 适合平板使用。

## 10. 第一阶段完成标准

第一阶段达到以下条件时，可视为完成：

- 五种身份均可进入对应演示端口。
- 学生可以体验 5 个单元、13 次课程。
- 教师可以查看课程、班级、学习进度和作品。
- 家长可以查看学习进度和成果。
- 总部可以查看课程结构、校区和整体数据。
- 合作伙伴可以查看所属校区的班级、教师和课程数据。
- 产品使用模拟身份和模拟数据运行。
- 网站可以独立运行和部署。
- 产品未加入第一阶段明确排除的功能。

# Vibe Coding 创意编程课程平台角色矩阵

## 1. 文档目的

本文档用于明确 Vibe Coding 创意编程课程平台第一阶段的角色、核心任务、可查看内容、可操作内容和使用限制。

第一阶段使用模拟身份和模拟数据，不建立真实登录、真实组织管理或复杂权限体系。

## 2. 角色矩阵

| 角色 | 核心任务 | 可查看内容 | 可操作内容 | 第一阶段限制 |
| --- | --- | --- | --- | --- |
| 总部 | 了解平台整体运营情况；查看课程结构和课程使用情况 | 整体运营数据；校区、班级、教师和学生数量；13 课课程结构；原子组件库；不同课程的完成率和作品数量 | 通过总部演示端口切换和查看相应数据页面 | 不进行真实组织管理；不进行真实权限分配；所有数据均为演示数据 |
| 合作伙伴 | 了解所属校区的教学与运营情况 | 所属校区；教师、班级和排课；校区课程进度；校区运营数据 | 通过合作伙伴演示端口查看所属校区的数据 | 只能查看所属校区的模拟数据；不能查看其他校区数据；不包含真实权限管理 |
| 教师 | 查看课程和班级学习情况；跟进学生进度、测试与作品 | 自己的班级；13 节课程预览；学生学习进度；学生测试结果；学生作品 | 预览课程；查看班级和学生信息；添加模拟评价 | 不进行真实账号邀请；身份、班级和学生数据均为模拟数据 |
| 学生 | 按课程地图完成 13 节课程和互动实验；形成课程作品 | 自己的课程地图；13 节课程；自己的学习进度；自己的课程作品；自己的课程奖励 | 进入课程；完成互动实验；编辑代码；运行代码；保存学习进度；保存课程作品 | 暂不使用真实登录；学习进度、作品和奖励基于当前演示身份及本地数据 |
| 家长 | 了解孩子的学习进度、成果和教师评价 | 孩子的学习进度；课程成果；公开作品；教师评价 | 通过家长演示端口查看相应信息 | 不显示复杂代码；不显示详细调试记录；数据为演示数据 |

## 3. 身份体验入口

第一阶段通过身份切换提供不同角色的演示体验：

- 用户可以通过身份切换进入总部、合作伙伴、教师、学生和家长端口。
- 各端口必须明确标注当前使用演示数据。
- 第一阶段暂不使用真实登录。
- 身份切换只用于体验不同角色视图，不代表真实权限认证。

## 4. 第一阶段边界

第一阶段不扩展以下功能：

- 真实财务功能。
- 支付功能。
- 真实招生功能。
- 复杂权限功能。

一张网页，看懂 整个创意编程平台

Vibe Coding Lab 是面向 10—15 岁学习者的五角色课程平台。 学生用 13 节课持续完成同一个网页应用，其他角色围绕同一份课程、项目与学习事实协作。

03 · SYSTEM ARCHITECTURE

内容、作品、进度与业务数据清晰分层

课程页与创造台读取同一项目，教师预览只读，工具修改可校验、可审计。

01

课程内容层

5 单元与 13 课保存在 JSON 中，页面不逐课写死。

content / Course / Lesson
02

校验与渲染层

Zod 校验课程内容，LessonRenderer 分发可复用互动原子。

Zod / LessonRenderer
03

持续创作层

13 个注册工具共同编辑同一份 ProjectDocument，并限制字段权限。

CourseToolHost / ProjectPatch
04

数据与存储层

课程进度、学生项目和模拟业务数据分层保存，通过仓储接口访问。

Repository / localStorage
05

五角色体验层

学生创作，教师与家长只读查看，总部与合作伙伴读取聚合视图。

RoleShell / ViewModel
互动原子

7 种可复用课程互动

点击揭晓单项选择文本输入 代码与互动预览安全规则检查 结构化创造台课程创造工具
项目主线

一份 ProjectDocument 贯穿 13 课

第 01 课创建项目，第 02—13 课持续提交受字段权限约束的 patch；上游修改后，相关测试必须重新运行。

运行边界

为未来基础设施保留接口

当前用模拟数据和浏览器本地存储完成演示，Repository 隔离未来数据库迁移对页面和互动组件的影响。

PROJECT SUMMARY

这是一个由同一课程、同一项目和同一数据事实连接起来的五角色创意编程平台。
